# CSS Project

A collection of four web-based projects built with HTML, CSS, and JavaScript — featuring a **Password Generator**, a **Calculator**, a **Travel Website**, 
and a **Smart City Management Platform** with multiple dashboards.

---

## 🚀 Projects Overview

| Project | Description |
|---------|-------------|
| **Project 1: Password Generator** | Generate strong, secure passwords with customizable length and character sets (uppercase, lowercase, numbers, symbols). Includes strength indicator and custom password mode. |
| **Project 2: Calculator** | A simple and clean calculator for basic arithmetic operations (addition, subtraction, multiplication, division, percentage, and sign toggle). |
| **Project 3: Wanderlust Travel** | A travel website showcasing popular destinations, travel packages, pricing plans (in BDT), and a photo gallery. Built as a static brand page. |
| **Project 4: Smart City Management Platform** | A comprehensive management dashboard with **Citizen**, **Business**, and **Admin** portals. Includes login/registration, real-time metrics, recent complaints, and service usage analytics.

### ✨ Features by Project

## 🔐 Project 1: Password Generator
Adjustable password length (slider/input)
Toggle character sets: Uppercase, Lowercase, Numbers, Symbols
Custom password mode (type your own)
Real-time strength indicator: Weak → Good → Strong
One-click password generation
Privacy notice: "Your password is never stored or transmitted"



### 🧮 Project 2: Calculator
Basic operations: +, -, ×, ÷
Additional functions: AC (clear), ± (sign toggle), % (percentage)
Decimal point support
Clean, button-based interface


### ✈️ Project 3: Wanderlust Travel
Hero section with call-to-action
Popular destinations: Paris, Bali, Maldives (with prices in BDT)
Travel packages: Adventure, Family, Luxury
Pricing plans: Basic, Pro, Enterprise
Photo gallery and contact form
Fully responsive navigation

### 🏙️ Project 4: Smart City Management Platform
Authentication: Login and Registration forms
Role-based Dashboards:
Citizen: View healthcare, education, transport stats; recent complaints; upcoming appointments
Business: Revenue, orders, customers, deliveries; recent orders and top products
Admin: Total users, businesses, complaints, revenue; service usage breakdown
Interactive metrics with trend indicators (↑ / ↓)
Sidebar navigation with portal-specific menus
Language toggle (Bengali/English) and dark/light mode support
